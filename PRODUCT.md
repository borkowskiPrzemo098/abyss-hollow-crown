# Product context (Impeccable)

Inferred from the owner's written brief (2026-10-13); no interview — the brief itself was explicit and asked
not to be consulted on small decisions.

- **Product:** ABYSS: The Hollow Crown — mobile-first dark fantasy isometric action roguelite (PWA).
- **Players:** mobile gamers playing one-thumb-and-a-half sessions on iOS Safari / Android Chrome, often in dim rooms.
- **Surface modes:** in-game HUD = Operate (glanceable, never covers combat); title/pause/death = Experience
  (the world leads, UI recedes).
- **Brand world:** ruined kingdom, ash, stone, ember light vs hollow teal corruption. Red only for danger.
- **Type:** Grenze Gotisch (display), Alegreya Sans (UI, tabular numerals). No system display faces.
- **Constraints:** zero cost, no external CDNs at runtime, 44px+ touch targets, safe-area insets, no emoji icons.
- **Anti-references:** generic purple/blue gradients, centred hero-on-gradient, Bootstrap tiles, mobile-ad UI clutter.
